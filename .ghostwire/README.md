# Ghostwire Configuration

This directory contains Ghostwire configuration for this repository.

Ghostwire enables AI agents to interact with this codebase through a standardized API.

## What is Ghostwire?

Ghostwire is a bidirectional repository listener system that allows AI agents to:
- Read and write code
- Execute git operations
- Create pull requests
- Access file trees and content

## Configuration

- **config.json**: Main configuration file
- **README.md**: This file

## Security

Ghostwire requires authentication via API tokens. See the main Ghostwire documentation for security best practices.
